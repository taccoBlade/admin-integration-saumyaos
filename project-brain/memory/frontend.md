# Memory Domain: Frontend

## Core Components
- **Header**: Global menu and audio player deck. Player is active only on `/personal` or theme-activated routes.
- **Footer (Contact)**: Status banner, contact credentials, social anchors.
- **Home Screen Elements**: `InteractiveHero`, `FeaturedProjects` grids, `CareerTimeline`, `SkillsNetwork`.
- **Interactive Terminal Vault**: Displays dynamic, iframe-embedded panels representing dashboard telemetry widgets.
- **Personal Layout**: Spreads out photo assets in a grid layout reminiscent of print design lookbooks.
