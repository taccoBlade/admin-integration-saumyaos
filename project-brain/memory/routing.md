# Memory Domain: Routing

## Map Layout
- `/`: Primary engineering identity landing page.
- `/projects/[id]`: Technical case studies.
- `/projects/terminal-vault`: Interactive dashboard hub.
- `/personal`: Lifestyle content (cruiser telemetry, photography spreads).
- `/archive`: Public data lists (literature logs, spreadsheet calculators).
- `/contact`: Visual message terminal.
- `/lithos`: Geology spotlight showcase.
