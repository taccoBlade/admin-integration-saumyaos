# Memory Domain: Overview

## Project Summary
This repository contains the source code for the personal website of Saumya Parekh, styled as a modern, interactive Engineering Portfolio Operating System (SAUMYA.OS). It acts as a multi-perspective hub showcasing concrete engineering work, real-world internships (such as at CSSI), academic milestones (at PDEU), and personal tracking (motorcycling telemetry, gym stats, and swing trading models).

## High-Level Vision
- Replaces traditional chronological resumes with a cyber-industrial dashboard.
- Features immersive, interactive panels: computational 3D canvas (Three.js/Fiber), beliefs terminal, and dynamic motorcycle telemetry grids.
- Built to show deep engineering credibility, particularly bridging physical civil engineering (IS standard compliance) with software automation.
